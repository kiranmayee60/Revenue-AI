# 💰 Revenue AI

## AI-Powered Revenue Analysis & Prediction Dashboard

Revenue AI is a web-based dashboard that analyzes historical revenue data and predicts future revenue using Machine Learning.

## 🚀 Features

- 📂 CSV Revenue Data Upload
- 💰 Total Revenue Analysis
- 📊 Average Revenue Calculation
- 🚀 Highest Revenue Detection
- 📈 Historical Revenue Trend
- 🤖 AI Revenue Prediction
- 📊 Actual vs Predicted Revenue Visualization
- 💡 AI-Based Business Recommendations

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Matplotlib
- Scikit-learn
- Linear Regression
- GitHub

## ⚙️ How to Run

1. Clone the repository.
2. Install the required Python libraries.
3. Run the Streamlit application.

```bash
pip install streamlit pandas matplotlib scikit-learn
streamlit run app.py
